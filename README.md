# 역행렬 구하기 (Report 1)

n×n 정방행렬을 입력받아 **행렬식**과 **가우스-조던 소거법** 두 가지 방법으로 역행렬을 구하고, 두 결과가 같은지 비교하는 프로그램입니다.

## 실행 방법

```
python3 inverse_matrix.py
```

## 기능

1. **행렬 입력**: 차수 n(1~4)을 입력받고 행 단위로 행렬을 입력받아 2차원 리스트로 저장
2. **행렬식으로 역행렬 계산**: 여인수 전개로 행렬식을 구하고, 수반행렬을 행렬식으로 나눠 역행렬 계산
3. **가우스-조던 소거법으로 역행렬 계산**: 첨가행렬 [A | I]를 행연산으로 [I | A⁻¹]로 변환
4. **결과 출력 및 비교**: 두 방법의 결과를 출력하고 같은지 비교

역행렬이 존재하지 않는 경우(행렬식 = 0)에는 오류 메시지를 출력합니다.

### 추가 기능
- 가우스-조던 소거법의 행연산 과정(행 교환, 피벗 정규화, 소거)을 단계별로 출력

## 실행 예시

```
정방행렬의 차수를 입력하세요 (1~4): 3
1행: 2 5 7
2행: 6 3 4
3행: 5 -2 -3
...
두 방법의 결과가 동일합니다.
```
